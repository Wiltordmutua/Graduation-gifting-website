# Graduation Wishlist Website

A simple static website showcasing a graduation wishlist with image cards and personalized gift items.

## Project Overview

This project is a personal graduation gift list built using:
- HTML
- CSS
- JavaScript
- Local image assets

It displays each gift item with a title, description, and photo in a clean responsive gallery layout.

## Files Included

- `index.html` – main page structure and gift data
- `Styles.css` – styling and responsive layout
- `Images/` – project image assets

## How to View the Project

Open `index.html` in a browser to view the site.

If you want to run it locally using a simple server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

This project is designed as a personal graduation gift page and can be customized by editing the gift list in `index.html`.
